# AgriReach

The words farmers and extension officers use for crop advice that an officer checks before anyone can read it.

## Language

**Question**:
What a farmer asks about a crop, a place, or a farming problem.
_Avoid_: Case, ticket, reference number

**Advice**:
The answer a farmer can read after an extension officer has approved it and it has been released.
_Avoid_: Draft, approved text, delivery

**Review**:
An extension officer reading the question, the agricultural sources, and the safety findings before deciding.
_Avoid_: Queue item, workflow, gate

**Text update**:
An optional message to the farmer's phone about a question.
_Avoid_: Login, authentication, session

**Extension officer**:
The person who reviews a question and approves, rejects, or asks for a correction.
_Avoid_: Operator, admin, reviewer token
